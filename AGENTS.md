# How this is documented

As an AI Agent, you will fix the issue, and then write a file in incidents/ with name like 0001_issue_name.md

The file should have:
1. What happened
2. What you did to fix it
3. What you think will prevent it from happening again
4. Sign as yourself (codex, antigravity, etc) & date

and also write a summary in the section (#summary) in README.md below with:

1. Number + Title + Date
2. Short summary
3. Solved by (codex, etc)

Generate an image for every incident as well. Put it in incidents/ with name like 0001_issue_name.png and a link to it in incidents/README.md as well
